# Antigravity Physics Simulations

Antigravity Physics is a comprehensive, interactive, web-based physics simulation portal built for high school students (9th to 12th grades). It transforms abstract physics concepts into visual, interactive experiments using modern UI/UX design (dark mode, glassmorphism, glowing neon visuals) powered purely by HTML, CSS, and Vanilla JavaScript (`<canvas>`).

## Features

- **24 Unique Simulations**: Covering Mechanics, Electromagnetism, Thermodynamics, Optics, and Modern Physics.
- **Zero Dependencies**: Pure Vanilla JS, HTML, and CSS. No React, Vue, or heavy frameworks. (Uses Lucide for icons).
- **High Performance**: Physics engines and animations run on raw `requestAnimationFrame` and Canvas 2D API.
- **Modern Aesthetics**: Built with a "dark mode" tech-lab theme. Real-time dynamic coloring, interactive sliders, and glowing UI elements.
- **Responsive**: Fully responsive grid layouts using CSS Flexbox and Grid.

## How to Run

Since everything is built with Vanilla HTML/JS, you don't need any build tools.

1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).
3. Click on any simulation card to enter the interactive lab.

## Deployment to GitHub Pages

This project is completely static and can be hosted for free on **GitHub Pages**:
1. Push the repository to GitHub.
2. Go to your repository **Settings** > **Pages**.
3. Select the `main` branch and `/ (root)` folder.
4. Save, and your physics portal will be live in a few minutes!
